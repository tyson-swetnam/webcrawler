# AI University News Aggregator

Automated daily news aggregator tracking AI research and developments from 380+ universities and research facilities.

**Live Site:** https://tyson-swetnam.github.io/webcrawler

**Last Updated:** 2026-08-20 15:51 UTC

## About

This site automatically crawls university news sites daily and aggregates AI-related research news, with Claude-curated Top News, full-text search, and a DuckDB-WASM analytics dashboard.

## Sources

- Peer Institutions (top R1 universities)
- R1 Research Universities
- Major Research Facilities, National Laboratories, and Global Institutions

## Technology

- **Crawler:** Python + Scrapy
- **AI Analysis:** Claude (via Claude Code CLI, Max subscription)
- **Deployment:** GitHub Actions + GitHub Pages
- **Update Schedule:** Daily at 07:00 PST
